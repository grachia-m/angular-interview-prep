# Angular Interview Prep — Approved Design

## Intent

Create a warm, low-fatigue interview-preparation site for an Angular frontend developer with about five years of experience. Angular 16 is the user's strong baseline; Angular 18–22, RxJS/NgRx reasoning, and senior architectural judgment need more repetition.

## Chosen approach

The approved approach is an adaptive daily workout with visible structure. A fixed workout was rejected as insufficiently personal; a fully adaptive stream was rejected because it could feel random. The selected experience keeps the reliable sequence **Warm-up → Modern Angular → Code Challenge → RxJS/NgRx → Senior Scenario → Review**, while choosing content from weakness, confidence, recency, difficulty, mistakes, and selected Angular version.

## Required experience

- Global Angular 16–22 selector plus Mixed and Modern Focus modes; remember the choice.
- Daily workout, progressive answer reveals, confidence controls, bookmarks, mistakes, and spaced-repetition behavior.
- Quick Lookup with Ctrl/⌘+K and concise reference cards.
- Mock interview mode with middle/senior tracks and an interview-style result.
- Progress/readiness views without heavy gamification.
- Useful home shortcuts, including Interview Tomorrow and weak-area practice.
- Mid-to-senior content; no beginner-course framing or giant static question bank.

## Visual direction

Use warm cream and soft ivory surfaces, charcoal-brown text, muted terracotta accents, sage green support colors, and a warm dark code surface. The interface should feel like a focused reading notebook, not a SaaS analytics dashboard. It must remain responsive, keyboard accessible, and comfortable for extended reading.

## Builder calls

- Implement as a buildless static single-page site with small ES modules and browser-local persistence.
- Seed enough representative content to make every mode functional and believable; favor depth over an exhaustive database.
- Treat the adaptive score as an explainable local heuristic, not a claim of psychometric precision.

## Non-goals

Not a full Angular course, documentation clone, certification simulator, LeetCode product, or production learning-management backend.
